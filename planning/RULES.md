# Loyiha Qoidalari

## Tech Stack
- Frontend: Next typescript, Redux Toolkit, module.css
- Backend: Node.js, Express, MongoDB
- Real-time: Socket.io

## Kodlash Qoidalari (Coding Guidelines)
- Barcha React komponentlar functional component va TypeScript bilan yozilsin.
- Tushunarsiz va murakkab logikalar uchun qisqa izohlar (comments) qoldirilsin.
- UI uchun minimalist (Notion-inspired) dizayn uslubidan foydalanilsin.
-Emojilar ishlatilmasin
